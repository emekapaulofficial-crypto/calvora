Verify a Calvora ID

Check that an agent or staff member really works with Calvora.

The ID number is printed on the card, and the QR code opens this page with the number filled in.

What this page shows

Name, photo, ID number, whether the person is an agent or staff, whether the card is valid, and its expiry date. We never show phone numbers, addresses or identity documents here.

If a card is lost, expired, suspended or cancelled it shows as not valid. If someone claiming to be from Calvora shows you a card that does not check out here, do not pay them anything and report it to us.
